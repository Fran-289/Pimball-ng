Base de Datos (JSON)

Genera un archivo JSON con toda la información de tu sistema (Máquinas, Cortes, Tickets, Ubicaciones y Auditoría). Úsalo para restaurar tu sistema en otro dispositivo o en caso de emergencia.

Recomendación de Seguridad: Te sugerimos descargar un respaldo general del sistema al menos cada 15 días para mantener resguardada toda tu información.

Al restaurar un respaldo, se sobreescribirán todos los datos actuales con los del archivo. ¡Asegúrate de que es el archivo correcto!
