Respaldos y Exportación

Protege tu información creando copias de seguridad o exportando tus datos.

Base de Datos (JSON)

Genera un archivo JSON con toda la información de tu sistema (Máquinas, Cortes, Tickets y Ubicaciones). Úsalo para restaurar tu sistema en otro dispositivo o en caso de emergencia.

Al restaurar un respaldo, se sobreescribirán todos los datos actuales con los del archivo. ¡Asegúrate de que es el archivo correcto!

Exportar a Excel / CSV

Descarga tus datos en formato tabular para analizarlos en Excel, Google Sheets u otras herramientas de cálculo.
